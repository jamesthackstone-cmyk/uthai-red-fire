UTHAI RED FIRE — FREE WEBSITE

1. Open index.html to preview the site on your computer.
2. The site is static HTML/CSS/JS, so it can be hosted free on GitHub Pages or Cloudflare Pages.
3. Before accepting orders, edit index.html and replace:
   - YOUR-EMAIL@example.com
   - YOUR_LINE_ID
   - +66YOURNUMBER
   with your real contact details.
4. The order form uses FormSubmit.co. The first time an order is submitted,
   FormSubmit will ask you to confirm the receiving email address.
5. The site currently assumes ฿20 delivery within Uthai Town.
6. Pricing currently used:
   1 bottle = ฿150
   2 bottles = ฿200
   3 bottles = ฿350
   4 bottles = ฿400
   5 bottles = ฿550
   6 bottles = ฿600
   Delivery = ฿20.

No paid hosting is required for the static site.
